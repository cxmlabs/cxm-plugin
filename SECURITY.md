# Security policy

## Report a vulnerability

Do not open a public GitHub issue for a vulnerability.

Send the report to security@cloudexmachina.io. Include the affected version (`cxm --version`), the steps to reproduce, and the impact.

When this repository is public, you can also use GitHub private vulnerability reporting. Open the **Security** tab and select **Report a vulnerability**.

We acknowledge each report within 3 business days.

## Supported versions

Only the latest released version gets security fixes. To get a fix, update to the latest version.
